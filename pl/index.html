Jak stworzyć Multiboot USB?

Przewodnik po najlepszych metodach na jeden pendrive z wieloma systemami.

Ventoy
Bardzo łatwa

Rewolucyjna metoda. Instalujesz Ventoy na pendrive raz, a potem po prostu przeciągasz pliki .ISO na dysk jak zwykłe pliki.

Zalety:

  • Najszybsza metoda
  • Można mieszać systemy
  • Brak konieczności formatowania po dodaniu ISO

Wady:

  • Wymaga wsparcia UEFI/Legacy w specyficzny sposób

Platforma: Windows, Linux

Strona projektu Pobierz
YUMI (Your Universal Multiboot Installer)
Średnia

Klasyczne narzędzie, które pozwala wybrać systemy z listy podczas procesu tworzenia pendrive'a.

Zalety:

  • Bardzo stabilna
  • Duża biblioteka systemów
  • Działa świetnie na starszych komputerach

Wady:

  • Konieczność ponownego uruchomienia programu przy dodawaniu nowych systemów

Platforma: Windows, Linux

Pobierz
WinSetupFromUSB
Średnia

Specjalistyczne narzędzie skupiające się głównie na instalatorach systemów Windows (XP, 7, 8, 10, 11).

Zalety:

  • Najlepsza do systemów Windows
  • Obsługuje bardzo stare standardy

Wady:

  • Mniej intuicyjna dla systemów Linux

Platforma: Windows

Pobierz
Rufus (Single Boot/Manual)
Łatwa

Choć Rufus służy głównie do jednego systemu, można go użyć do przygotowania bazy pod bardziej zaawansowane metody.

Zalety:

  • Niezawodność
  • Szybkość

Wady:

  • Brak natywnego wsparcia dla multiboot

Platforma: Windows

Narzędzia ratunkowe

Przydają się, gdy system się nie uruchamia, trzeba zresetować hasło, odzyskać pliki albo naprawić bootloader.

  • Hiren's BootCD PE
    Zestaw narzędzi na bazie Windows PE: odzyskiwanie danych, reset haseł, partycje, diagnostyka. To projekt społeczności, nie oryginalnego autora, a jego strona jest oficjalnym źródłem tego projektu. Plik ISO ma ok. 3 GB.
    Pobierz
  • SystemRescue
    Lekki system Linux do naprawy i odzyskiwania danych (GParted, narzędzia systemów plików, dostęp do sieci). Obraz ma ok. 900 MB.
    Pobierz
  • Super Grub2 Disk
    Pomaga uruchomić system, gdy zepsuł się GRUB lub MBR, nawet bez dostępu do menu startowego.
    Pobierz
  • Ultimate Boot CD
    Klasyczny zestaw narzędzi diagnostycznych i naprawczych. Aktualizowany rzadko, więc nadaje się głównie do starszych komputerów.
    Pobierz

Partycje i dyski

  • GParted Live
    Graficzny edytor partycji w wersji Live. Zmienia rozmiar, przenosi i kopiuje partycje, obsługuje większość systemów plików.

  • SystemRescue
    Zawiera GParted oraz narzędzia konsolowe (parted, fdisk, ntfs-3g, testdisk) do pracy z dyskami i odzyskiwania danych.

    Zawiera graficzne menedżery partycji dla Windows i narzędzia do odzyskiwania danych.

Sprawdzanie pamięci RAM i dysków oraz wykrywanie usterek, gdy komputer się zawiesza lub restartuje.

  • MemTest86+
    Wolnoźródłowy test pamięci RAM. Uruchamia się bez systemu. Pozwól mu przejść co najmniej jeden pełny przebieg.
    Pobierz
  • MemTest86 (PassMark)
    Komercyjny, ale darmowy w wersji podstawowej test RAM od PassMark. Obsługuje UEFI i Secure Boot.

  • HDAT2
    Diagnostyka dysków twardych i SSD (SMART, test powierzchni, odczyt błędów).
    Pobierz
  • Ultimate Boot CD
    Zawiera wiele narzędzi do testowania procesora, pamięci i dysków, w tym narzędzia producentów dysków.
    Pobierz

Pendrive nie działa? Jak go naprawić

Po utworzeniu bootowalnego pendrive (Linux, instalator Windows, obraz ISO, Ventoy) system często widzi tylko mały fragment pojemności, pokazuje błędne partycje albo odmawia formatowania. Najskuteczniejszy sposób to całkowite wyczyszczenie struktury partycji i utworzenie jej od nowa.

Poniższe kroki trwale usuwają wszystkie dane z wybranego dysku. Pomyłka w numerze dysku (Windows) lub nazwie urządzenia (Linux) może skasować dysk systemowy. Przed każdym poleceniem sprawdź rozmiar i model nośnika.
Typowe objawy
  • Pendrive pokazuje się z bardzo małą pojemnością (np. 32 GB jako 50 MB).
  • Windows pisze „Nie można ukończyć formatowania” albo pokazuje kilka dziwnych partycji.
  • Dysk jest widoczny w Zarządzaniu dyskami, ale nie ma litery lub opcji „Formatuj”.

Windows: Diskpart

Wbudowane narzędzie wiersza poleceń, które czyści tablicę partycji i pozwala utworzyć ją od początku.

  1. Podłącz pendrive i zamknij okna, które z niego korzystają.
  2. Naciśnij Win, wpisz cmd, kliknij prawym przyciskiem Wiersz polecenia i wybierz Uruchom jako administrator.
  3. Uruchom narzędzie: diskpart
  4. Wyświetl dyski: list disk. Rozpoznaj pendrive po rozmiarze (kolumna Size), np. „Disk 2”.
  5. Wybierz pendrive: select disk 2 (wpisz numer swojego pendrive!). Sprawdź wybór poleceniem detail disk.
  6. Jeśli dysk jest chroniony przed zapisem: attributes disk clear readonly
  7. Usuń wszystkie partycje: clean. Do dokładnego wyzerowania całego nośnika (trwa długo) użyj clean all.
  8. Utwórz nową partycję: create partition primary
  9. Sformatuj ją: format fs=fat32 quick. Dla dużych plików lub pendrive powyżej 32 GB użyj format fs=exfat quick lub format fs=ntfs quick.
  10. Nadaj literę dysku: assign, a potem zamknij narzędzie: exit.

Linux:

Do tych kroków wystarczą narzędzia dostępne w większości dystrybucji (lsblk, wipefs, parted, mkfs). Działają z uprawnieniami sudo.

  1. Podłącz pendrive i wyświetl dyski: lsblk -o NAME,SIZE,MODEL,TRAN. Pendrive ma zwykle transport usb i nazwę typu /dev/sdb. /dev/sda to najczęściej dysk systemowy!
  2. Odmontuj wszystkie partycje pendrive: sudo umount /dev/sdb* (komunikaty o niezamontowanych partycjach możesz zignorować).
  3. Usuń sygnatury systemów plików i tablic partycji: sudo wipefs --all /dev/sdb
  4. Dla pewności wyzeruj początek nośnika: sudo dd if=/dev/zero of=/dev/sdb bs=1M count=100
  5. Utwórz nową tablicę i partycję: sudo parted -s /dev/sdb mklabel msdos sudo parted -s /dev/sdb mkpart primary 1MiB 100%
  6. Sformatuj partycję: sudo mkfs.vfat -F 32 -n PENDRIVE /dev/sdb1. Zamiast FAT32 możesz użyć sudo mkfs.exfat /dev/sdb1 albo sudo mkfs.ext4 /dev/sdb1.
  7. Zapisz dane i bezpiecznie wysuń nośnik: sync && sudo eject /dev/sdb
Wolisz interfejs graficzny? W aplikacji Dyski (GNOME Disks) wybierz pendrive, z menu wybierz „Formatuj dysk…” i ustaw Partycjonowanie: Kompatybilne ze wszystkimi systemami (MBR). Możesz też użyć GParted: Urządzenie → Utwórz tablicę partycji.
Jeśli to nie pomaga
  • Pendrive nie pojawia się w list disk / lsblk: spróbuj innego portu USB (najlepiej bezpośrednio w komputerze, bez huba) i innego kabla lub komputera.
  • Pojawia się błąd zapisu lub nośnik zmienia się w tylko do odczytu: pendrive może mieć przełącznik blokady zapisu albo kość pamięci jest uszkodzona.
  • Pojemność nadal jest błędna po clean: pendrive może być podróbką (fałszywa pojemność). Sprawdź go narzędziami F3 (Linux/macOS) lub H2testw (Windows).
  • Gdy nic nie działa, wypróbuj program Rufus: wybierz pendrive, ustaw schemat MBR i system FAT32 lub exFAT, a następnie kliknij START.

Ventoy – tworzenie bootowalnego pendrive
  1. Pobierz najnowszą wersję Ventoy (ventoy-x.y.z-windows.zip) i rozpakuj archiwum.
  2. Podłącz pendrive (zrób kopię danych – instalacja go sformatuje).
  3. Uruchom Ventoy2Disk.exe (na Linuksie: sudo sh Ventoy2Disk.sh -i /dev/sdX).
  4. Wybierz pendrive z listy Device. W menu Option → Partition Style wybierz GPT dla nowszych komputerów UEFI lub MBR dla starszych.
  5. Kliknij Install i dwukrotnie potwierdź ostrzeżenie o utracie danych.
  6. Po zakończeniu na pendrive pojawi się partycja Ventoy. Skopiuj na nią pliki .ISO (Windows, Linux, narzędzia) zwykłym kopiowaniem.
  7. Uruchom komputer z pendrive (klawisz wyboru bootowania: F12, F10, Esc lub F8 – zależnie od producenta) i wybierz obraz z menu Ventoy.

YUMI (Your Universal Multiboot Installer) – tworzenie bootowalnego pendrive
  1. Pobierz YUMI (wersja exFAT dla plików ISO powyżej 4 GB i systemów UEFI, wersja BIOS dla starszych komputerów) – instalacja nie jest wymagana.
  2. Podłącz pendrive i uruchom plik YUMI jako administrator.
  3. Zaakceptuj licencję i wybierz literę pendrive w kroku 1.
  4. W kroku 2 wybierz dystrybucję z listy (np. Ubuntu). Zaznacz opcję formatowania przy pierwszym użyciu.
  5. W kroku 3 wskaż pobrany plik ISO (lub użyj opcji Download the ISO), po czym kliknij Create.
  6. Po zakończeniu YUMI zapyta, czy dodać kolejny system – potwierdź i powtórz kroki 2–3 dla każdego kolejnego ISO.
  7. Uruchom komputer z pendrive i wybierz system z menu startowego.
Pobierz
WinSetupFromUSB – tworzenie bootowalnego pendrive
  1. Pobierz WinSetupFromUSB, uruchom samorozpakowujące się archiwum i wybierz wersję 64-bitową (WinSetupFromUSB_x64.exe).
  2. Podłącz pendrive i wybierz go w polu USB disk selection.
  3. Zaznacz Auto format it with FBinst (wybierz FAT32; dla ISO powyżej 4 GB – NTFS, ale wtedy tylko tryb BIOS/Legacy).
  4. Zaznacz sekcję systemu, który dodajesz (np. Vista/7/8/10/11/Server) i wskaż plik ISO przyciskiem …. Dla Linuksa użyj sekcji Linux ISO/Other Grub4dos compatible ISO.
  5. Kliknij GO i potwierdź ostrzeżenia. Poczekaj na komunikat Job done.
  6. Kolejne systemy dodajesz, uruchamiając program ponownie – tym razem bez zaznaczania formatowania.
  7. Przetestuj pendrive w emulatorze QEMU (opcja Test in QEMU) lub uruchom z niego komputer.
Pobierz
Rufus (Single Boot/Manual) – tworzenie bootowalnego pendrive
  1. Pobierz Rufus (wersja przenośna nie wymaga instalacji) i uruchom go.
  2. Podłącz pendrive – zostanie wykryty automatycznie w polu Urządzenie (kopia danych obowiązkowa, dysk zostanie wyczyszczony).
  3. Kliknij WYBIERZ i wskaż plik ISO systemu.
  4. Wybierz schemat partycji: GPT dla UEFI lub MBR dla BIOS/Legacy (Rufus podpowie wartość dla danego obrazu).
  5. Kliknij START, w razie pytania wybierz tryb zapisu obrazu ISO i potwierdź.
  6. Uruchom komputer z pendrive. Aby uzyskać multiboot, możesz w ten sposób zrobić pendrive z jednym systemem albo użyć Ventoy.
