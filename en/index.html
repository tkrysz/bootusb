How to create a Multiboot USB?

A guide to the best ways to put multiple operating systems on a single flash drive.

Ventoy
Very easy

A revolutionary method. You install Ventoy on the flash drive once, and from then on you simply drag and drop .ISO files onto it like ordinary files.

Pros:

  • Fastest method
  • Mix different operating systems
  • No need to reformat after adding an ISO

Cons:

  • Needs UEFI/Legacy support in a specific way

Platform: Windows, Linux

Project website Download
YUMI (Your Universal Multiboot Installer)
Medium

A classic tool that lets you pick systems from a list while the flash drive is being created.

Pros:

  • Very stable
  • Large library of systems
  • Works great on older computers

Cons:

  • You must run the program again each time you add a new system

Platform: Windows, Linux

Download
WinSetupFromUSB
Medium

A specialist tool focused mainly on Windows installers (XP, 7, 8, 10, 11).

Pros:

  • Best for Windows systems
  • Supports very old standards

Cons:

  • Less intuitive for Linux systems

Platform: Windows

Download
Rufus (Single Boot/Manual)
Easy

Although Rufus is mainly meant for a single system, it can be used to prepare a base for more advanced methods.

Pros:

  • Reliable
  • Fast

Cons:

  • No native multiboot support

Platform: Windows

Warning: creating a bootable USB drive erases all data on the device. Make a backup first. Download tools only from official websites and, if possible, verify the checksums of ISO files.

Rescue tools

Useful when the system won't boot, you need to reset a password, recover files or repair the bootloader.

  • Hiren's BootCD PE
    A toolkit based on Windows PE: data recovery, password reset, partitioning, diagnostics. It is a community project, not by the original author, and this site is that project's official source. The ISO is about 3 GB.
    Download
  • SystemRescue
    A lightweight Linux system for repair and data recovery (GParted, filesystem tools, networking). The image is about 900 MB.
    Download
  • Super Grub2 Disk
    Helps boot a system when GRUB or the MBR is broken, even without a working boot menu.
    Download
  • Ultimate Boot CD
    A classic set of diagnostic and repair tools. Rarely updated, so best suited to older computers.

Resize, create and delete partitions, copy data and repair the partition table without booting the installed system.

    A graphical partition editor in Live form. Resizes, moves and copies partitions and supports most filesystems.

Hardware diagnostics

Check RAM and drives and track down faults when the computer freezes or reboots.

    An open-source RAM test. Runs without an operating system. Let it finish at least one full pass.

    A commercial RAM tester from PassMark that is free in its basic edition. Supports UEFI and Secure Boot.
    Download
  • HDAT2
    Diagnostics for hard drives and SSDs (SMART, surface test, error reading).

  • Ultimate Boot CD

Ventoy – creating a bootable USB drive
  1. Download the latest Ventoy release (ventoy-x.y.z-windows.zip) and extract the archive.
  2. Plug in the USB drive (back up your data – the installation will format it).
  3. Run Ventoy2Disk.exe (on Linux: sudo sh Ventoy2Disk.sh -i /dev/sdX).
  4. Select your drive in the Device list. In Option → Partition Style choose GPT for modern UEFI computers or MBR for older ones.
  5. Click Install and confirm the data-loss warning twice.
  6. When it finishes, a Ventoy partition appears on the drive. Copy your .ISO files (Windows, Linux, utilities) onto it like regular files.
  7. Boot the computer from the USB drive (boot menu key: F12, F10, Esc or F8 – depends on the manufacturer) and pick an image from the Ventoy menu.

YUMI (Your Universal Multiboot Installer) – creating a bootable USB drive
  1. Download YUMI (the exFAT version for ISO files over 4 GB and UEFI systems, the BIOS version for older computers) – no installation required.
  2. Plug in the USB drive and run YUMI as administrator.
  3. Accept the license and select the drive letter in step 1.
  4. In step 2 choose a distribution from the list (e.g. Ubuntu). Tick the format option on first use.
  5. In step 3 point to the downloaded ISO file (or use Download the ISO), then click Create.
  6. When done, YUMI asks whether to add another system – confirm and repeat steps 2–3 for each additional ISO.
  7. Boot the computer from the USB drive and choose a system from the boot menu.

WinSetupFromUSB – creating a bootable USB drive
  1. Download WinSetupFromUSB, run the self-extracting archive and pick the 64-bit version (WinSetupFromUSB_x64.exe).
  2. Plug in the USB drive and select it in the USB disk selection field.
  3. Tick Auto format it with FBinst (choose FAT32; for ISO files over 4 GB use NTFS, but then only BIOS/Legacy mode works).
  4. Tick the section for the system you are adding (e.g. Vista/7/8/10/11/Server) and select the ISO file with the … button. For Linux use the Linux ISO/Other Grub4dos compatible ISO section.
  5. Click GO and confirm the warnings. Wait for the Job done message.
  6. To add more systems, run the program again – this time without ticking the format option.
  7. Test the drive in the QEMU emulator (Test in QEMU option) or boot a computer from it.

Rufus (Single Boot/Manual) – creating a bootable USB drive
  1. Download Rufus (the portable version needs no installation) and run it.
  2. Plug in the USB drive – it is detected automatically in the Device field (a backup is a must, the drive will be wiped).
  3. Click SELECT and choose the system's ISO file.
  4. Choose the partition scheme: GPT for UEFI or MBR for BIOS/Legacy (Rufus suggests a value for the given image).
  5. Click START, choose ISO image mode if asked, and confirm.
  6. Boot the computer from the USB drive. For multiboot you can use this to make a single-system drive, or use Ventoy instead.
