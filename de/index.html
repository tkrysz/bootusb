Wie erstellt man einen Multiboot-USB-Stick?

Ein Leitfaden zu den besten Methoden, mehrere Betriebssysteme auf einem USB-Stick unterzubringen.

Ventoy
Sehr einfach

Eine revolutionäre Methode. Sie installieren Ventoy einmal auf dem USB-Stick und ziehen danach einfach .ISO-Dateien wie normale Dateien darauf.

Vorteile:

  • Schnellste Methode
  • Verschiedene Systeme mischbar
  • Kein erneutes Formatieren nach dem Hinzufügen einer ISO nötig

Nachteile:

  • Benötigt UEFI-/Legacy-Unterstützung auf spezielle Weise

Plattform: Windows, Linux

Projektseite Herunterladen
YUMI (Your Universal Multiboot Installer)
Mittel

Ein klassisches Tool, mit dem Sie beim Erstellen des USB-Sticks Systeme aus einer Liste auswählen.

Vorteile:

  • Sehr stabil
  • Große Auswahl an Systemen
  • Funktioniert hervorragend auf älteren Rechnern

Nachteile:

  • Das Programm muss für jedes neue System erneut gestartet werden

Plattform: Windows, Linux

Herunterladen
WinSetupFromUSB
Mittel

Ein Spezialwerkzeug, das sich vor allem auf Windows-Installationsmedien (XP, 7, 8, 10, 11) konzentriert.

Vorteile:

  • Am besten für Windows-Systeme
  • Unterstützt sehr alte Standards

Nachteile:

  • Für Linux-Systeme weniger intuitiv

Plattform: Windows

Herunterladen
Rufus (Single Boot/Manual)
Einfach

Obwohl Rufus hauptsächlich für ein einzelnes System gedacht ist, lässt es sich als Grundlage für fortgeschrittenere Methoden verwenden.

Vorteile:

  • Zuverlässig
  • Schnell

Nachteile:

  • Keine native Multiboot-Unterstützung

Plattform: Windows

USB-Stick funktioniert nicht? So reparieren Sie ihn

Nach dem Erstellen eines bootfähigen Sticks (Linux, Windows-Installer, ISO-Image, Ventoy) zeigt das System oft nur einen kleinen Teil der Kapazität an, listet seltsame Partitionen auf oder verweigert das Formatieren. Am wirksamsten ist es, die Partitionsstruktur vollständig zu löschen und neu anzulegen.

Die folgenden Schritte löschen alle Daten auf dem gewählten Datenträger unwiderruflich. Eine falsche Datenträgernummer (Windows) oder ein falscher Gerätename (Linux) kann Ihre Systemplatte löschen. Prüfen Sie vor jedem Befehl Größe und Modell des Datenträgers.
Typische Anzeichen
  • Der Stick zeigt nur eine winzige Kapazität (z. B. 32 GB als 50 MB).
  • Windows meldet „Die Formatierung konnte nicht abgeschlossen werden“ oder zeigt mehrere seltsame Partitionen.
  • Der Datenträger ist in der Datenträgerverwaltung sichtbar, hat aber keinen Laufwerksbuchstaben oder keine Option „Formatieren“.

Windows: Diskpart

Ein integriertes Kommandozeilenwerkzeug, das die Partitionstabelle löscht und eine neue von Grund auf anlegen lässt.

  1. Stecken Sie den Stick an und schließen Sie alle Fenster, die ihn verwenden.
  2. Drücken Sie Win, geben Sie cmd ein, klicken Sie mit der rechten Maustaste auf Eingabeaufforderung und wählen Sie Als Administrator ausführen.
  3. Starten Sie das Werkzeug: diskpart
  4. Datenträger anzeigen: list disk. Erkennen Sie Ihren Stick an der Größe (Spalte Size), z. B. „Disk 2“.
  5. Stick auswählen: select disk 2 (geben Sie die Nummer Ihres eigenen Sticks ein!). Prüfen Sie die Auswahl mit detail disk.
  6. Falls der Datenträger schreibgeschützt ist: attributes disk clear readonly
  7. Alle Partitionen entfernen: clean. Um den gesamten Datenträger gründlich mit Nullen zu überschreiben (dauert lange), nutzen Sie clean all.
  8. Neue Partition anlegen: create partition primary
  9. Formatieren: format fs=fat32 quick. Für große Dateien oder Sticks über 32 GB nutzen Sie format fs=exfat quick oder format fs=ntfs quick.
  10. Laufwerksbuchstaben zuweisen: assign, danach das Werkzeug beenden: exit.

Linux: Terminal

Für diese Schritte genügen Werkzeuge, die in den meisten Distributionen vorhanden sind (lsblk, wipefs, parted, mkfs). Führen Sie sie mit sudo aus.

  1. Stecken Sie den Stick an und listen Sie die Datenträger auf: lsblk -o NAME,SIZE,MODEL,TRAN. Ein USB-Stick hat meist den Transport usb und einen Namen wie /dev/sdb. /dev/sda ist meist die Systemplatte!
  2. Hängen Sie alle Partitionen des Sticks aus: sudo umount /dev/sdb* (Meldungen zu nicht eingehängten Partitionen können Sie ignorieren).
  3. Signaturen von Dateisystemen und Partitionstabellen entfernen: sudo wipefs --all /dev/sdb
  4. Zur Sicherheit den Anfang des Datenträgers mit Nullen überschreiben: sudo dd if=/dev/zero of=/dev/sdb bs=1M count=100
  5. Neue Tabelle und Partition anlegen: sudo parted -s /dev/sdb mklabel msdos sudo parted -s /dev/sdb mkpart primary 1MiB 100%
  6. Partition formatieren: sudo mkfs.vfat -F 32 -n PENDRIVE /dev/sdb1. Statt FAT32 können Sie sudo mkfs.exfat /dev/sdb1 oder sudo mkfs.ext4 /dev/sdb1 verwenden.
  7. Daten schreiben und den Stick sicher auswerfen: sync && sudo eject /dev/sdb
Lieber grafisch? Wählen Sie in Laufwerke (GNOME Disks) den Stick aus, im Menü „Datenträger formatieren…“ und stellen Sie Partitionierung: Kompatibel mit allen Systemen und Geräten (MBR) ein. Alternativ nutzen Sie GParted: Gerät → Partitionstabelle erstellen.
Wenn das nicht hilft
  • Der Stick erscheint nicht in list disk / lsblk: Versuchen Sie einen anderen USB-Anschluss (am besten direkt am Rechner, ohne Hub) und ein anderes Kabel oder einen anderen Rechner.
  • Schreibfehler treten auf oder der Stick wird schreibgeschützt: Er hat womöglich einen Schreibschutzschalter oder der Speicherchip ist beschädigt.
  • Die Kapazität ist nach clean noch immer falsch: Der Stick könnte eine Fälschung mit gefälschter Kapazität sein. Testen Sie ihn mit F3 (Linux/macOS) oder H2testw (Windows).
  • Wenn nichts hilft, probieren Sie Rufus: Stick auswählen, Schema MBR und FAT32 oder exFAT einstellen und auf START klicken.

Ventoy – bootfähigen USB-Stick erstellen
  1. Laden Sie die neueste Ventoy-Version (ventoy-x.y.z-windows.zip) herunter und entpacken Sie das Archiv.
  2. Stecken Sie den USB-Stick an (sichern Sie Ihre Daten – die Installation formatiert ihn).
  3. Starten Sie Ventoy2Disk.exe (unter Linux: sudo sh Ventoy2Disk.sh -i /dev/sdX).
  4. Wählen Sie den Stick in der Liste Device aus. Wählen Sie unter Option → Partition Style GPT für neuere UEFI-Rechner oder MBR für ältere.
  5. Klicken Sie auf Install und bestätigen Sie die Warnung vor Datenverlust zweimal.
  6. Danach erscheint auf dem Stick eine Partition Ventoy. Kopieren Sie Ihre .ISO-Dateien (Windows, Linux, Tools) einfach dorthin.
  7. Starten Sie den Rechner vom USB-Stick (Boot-Menü-Taste: F12, F10, Esc oder F8 – je nach Hersteller) und wählen Sie ein Image im Ventoy-Menü aus.

YUMI (Your Universal Multiboot Installer) – bootfähigen USB-Stick erstellen
  1. Laden Sie YUMI herunter (die exFAT-Version für ISO-Dateien über 4 GB und UEFI-Systeme, die BIOS-Version für ältere Rechner) – eine Installation ist nicht nötig.
  2. Stecken Sie den USB-Stick an und starten Sie YUMI als Administrator.
  3. Akzeptieren Sie die Lizenz und wählen Sie in Schritt 1 den Laufwerksbuchstaben des Sticks.
  4. Wählen Sie in Schritt 2 eine Distribution aus der Liste (z. B. Ubuntu). Aktivieren Sie bei der ersten Verwendung die Formatierungsoption.
  5. Geben Sie in Schritt 3 die heruntergeladene ISO-Datei an (oder nutzen Sie Download the ISO) und klicken Sie auf Create.
  6. Anschließend fragt YUMI, ob ein weiteres System hinzugefügt werden soll – bestätigen Sie und wiederholen Sie die Schritte 2–3 für jede weitere ISO.
  7. Starten Sie den Rechner vom USB-Stick und wählen Sie ein System im Startmenü.

WinSetupFromUSB – bootfähigen USB-Stick erstellen
  1. Laden Sie WinSetupFromUSB herunter, starten Sie das selbstextrahierende Archiv und wählen Sie die 64-Bit-Version (WinSetupFromUSB_x64.exe).
  2. Stecken Sie den USB-Stick an und wählen Sie ihn im Feld USB disk selection aus.
  3. Aktivieren Sie Auto format it with FBinst (wählen Sie FAT32; für ISO-Dateien über 4 GB NTFS, dann funktioniert aber nur der BIOS-/Legacy-Modus).
  4. Aktivieren Sie den Bereich des hinzuzufügenden Systems (z. B. Vista/7/8/10/11/Server) und wählen Sie die ISO-Datei über die Schaltfläche …. Für Linux nutzen Sie den Bereich Linux ISO/Other Grub4dos compatible ISO.
  5. Klicken Sie auf GO und bestätigen Sie die Warnungen. Warten Sie auf die Meldung Job done.
  6. Weitere Systeme fügen Sie hinzu, indem Sie das Programm erneut starten – diesmal ohne die Formatierungsoption.
  7. Testen Sie den Stick im QEMU-Emulator (Option Test in QEMU) oder starten Sie einen Rechner davon.
Herunterladen
Rufus (Single Boot/Manual) – bootfähigen USB-Stick erstellen
  1. Laden Sie Rufus herunter (die portable Version benötigt keine Installation) und starten Sie es.
  2. Stecken Sie den USB-Stick an – er wird im Feld Laufwerk automatisch erkannt (ein Backup ist Pflicht, der Stick wird gelöscht).
  3. Klicken Sie auf AUSWAHL und wählen Sie die ISO-Datei des Systems.
  4. Wählen Sie das Partitionsschema: GPT für UEFI oder MBR für BIOS/Legacy (Rufus schlägt einen Wert für das jeweilige Image vor).
  5. Klicken Sie auf START, wählen Sie bei Nachfrage den ISO-Image-Modus und bestätigen Sie.
  6. Starten Sie den Rechner vom USB-Stick. Für Multiboot können Sie so einen Stick mit einem System erstellen oder stattdessen Ventoy verwenden.
